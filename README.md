# 🛡 CyberGuard

CyberGuard is a Flask-based Web Application Security Scanner that helps analyze the security posture of websites by checking HTTPS, SSL certificates, security headers, cookies, server information, and more.

---

## ✨ Features

- 🌐 Website Reachability Check
- 🔒 HTTPS Verification
- 🛡 Security Headers Analysis
- 📜 SSL Certificate Validation
- 🍪 Cookie Security Check
- 🖥 Server Information Detection
- 📊 Security Score Calculation
- 📋 Security Summary
- 💾 Scan History (SQLite)

---

## 🚀 Installation

```bash
git clone https://github.com/Twinklenath/CyberGuard.git
cd CyberGuard

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
